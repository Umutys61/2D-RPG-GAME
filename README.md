# 🎮 2D RPG Game (Unity)

A prototype 2D RPG game developed with **Unity** and **C#**.  
This project focuses on implementing core RPG mechanics such as player movement, enemy interactions, and combat systems.

The project is being developed as part of my learning process in **game development and software engineering**.

---

## 🚀 Features

- Player movement system
- Enemy AI behavior
- Health system
- Basic combat mechanics
- 2D RPG gameplay structure
- Inventory system
- Level progression
- Save / load system

---

## 📌 Future Improvements

- Additional maps and environments
- New enemy types
- Boss fight system
- Skill system
- Level progression
- Sound effects and background music
- UI improvements
- Game balancing and polishing

## 🛠 Technologies Used

- **Unity Engine**
- **C#**
- **Git & GitHub**
- **Visual Studio**

Assets/ → Game assets, scripts, scenes

## 🎮 How to Run the Project!

1. Clone the repository

2. Open **Unity Hub**

3. Click **Add Project**

4. Select the cloned project folder

5. Open the project with a compatible Unity version
